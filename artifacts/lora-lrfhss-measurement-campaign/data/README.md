# Dataset location

The full measurement database is intentionally not duplicated in the Spark Lab website repository.

Use the canonical public dataset:

- Repository: <https://github.com/AlexisDel/LoRa-LRFHSS-Measurement-Campaign>
- SQLite database: <https://github.com/AlexisDel/LoRa-LRFHSS-Measurement-Campaign/blob/main/database.db>

The database contains 7,435 measurement points in the `data` table.
